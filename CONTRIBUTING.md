# Contributing

Thanks for helping improve these guides.

## Guide Contributions
- Keep steps beginner-friendly and ordered from a fresh save.
- Include source links for items, spells, talismans, tears, and route-critical locations.
- Mark optional steps clearly.
- Avoid major spoilers unless the guide is explicitly late-game.

## Asset Contributions
- Use original assets or assets with clear permission.
- Do not upload copyrighted screenshots from third-party wikis.
- Label stylized maps as route aids rather than exact maps.

## Review Checklist
- Open `index.html` locally.
- Test checklist persistence by checking a step and refreshing.
- Test mobile width if changing layout.
- Confirm changed links open useful references.

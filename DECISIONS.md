# Decisions

## Static Site First
- Decision: Use static HTML, CSS, and vanilla JavaScript.
- Reason: The project is empty, the requested output is a shareable guide, and GitHub Pages can host it without infrastructure.

## Original Marked Maps
- Decision: Use original SVG route maps instead of embedded game map screenshots.
- Reason: This avoids unclear copyright around game map imagery while still giving players visual route guidance.

## Wiki Links For Verification
- Decision: Link to wiki pages for item details and exact locations.
- Reason: Wiki pages are better for ongoing corrections, while this repo focuses on a curated route.
